# Chop — پنل مدیریت VLESS (نسخه‌ی Aurora)

پنل مدیریت VLESS روی Railway (یا هر هاست Node.js دیگه). **بدون نیاز به Redis**،
با حافظه‌ی درون‌پروسه‌ای + پایداری روی فایل JSON.

## ✨ تغییرات نسخه‌ی ۲.۰ (Aurora)

### بدون نیاز به Redis
- لایه‌ی ذخیره‌سازی به‌طور کامل بازنویسی شد و به‌جای Redis از حافظه‌ی درون‌پروسه‌ای
  استفاده می‌کنه.
- داده‌ها هر چند ثانیه روی یک فایل JSON ذخیره می‌شن تا بعد از ریستارت بمونن.
- برای پایداری کامل روی Railway: یک **Volume Mount** به مسیر `/data` بسازید و
  `DATA_FILE=/data/chop-data.json` رو ست کنید. اگر ست نشه، فایل در پوشه‌ی جاری
  پروژه نوشته می‌شه (که روی Railway بدون volume با هر ریستارت ریست می‌شه).

### یوزر و پسورد پیش‌فرض
- یوزرنیم و پسورد پیش‌فرض هر دو **`2010`** هستند — نیازی به تنظیم env نیست.
- بعد از دیپلوی، با `2010` / `2010` وارد شوید.
- برای امنیت بیشتر در پروداکشن: `ADMIN_USER` و `ADMIN_PASS` رو ست کنید.

### رابط کاربری جدید (Aurora)
- سایدبار شیشه‌ای با آیکون‌ها
- ۵ تم رنگی (Aurora، Cyber، Sunset، Royal، Light)
- پس‌زمینه‌ی animated aurora + ذرات کانوسی که به موس واکنش نشون می‌دن
- پالت دستورات (Ctrl/⌘+K)
- انتخاب گروهی کانفیگ‌ها
- داشبورد وضعیت سیستم زنده (CPU، RAM، load، اتصال‌های WS)
- صفحه‌ی فعالیت زنده
- خروجی CSV
- میانبرهای کیبورد
- توست با نوار پیشرفت + افکت صوتی اختیاری
- نمودار ترافیک با gradient و tooltip تعاملی

## پیش‌نیازها

- یه اکانت Railway (یا هر هاست Node.js که پروسه‌ی درازمدت اجرا کنه).
- **بدون Redis.** بدون دیتابیس خارجی. فقط Node.js ۲۰+.

## Environment Variables

| متغیر | اجباری | توضیح |
|---|---|---|
| `PORT` | نه، خودکاره | Railway خودش تزریق می‌کنه |
| `ADMIN_USER` | خیر | پیش‌فرض `2010` |
| `ADMIN_PASS` | خیر | پیش‌فرض `2010` |
| `SESSION_SECRET` | خیر (توصیه‌شده) | یه رشته‌ی تصادفی برای امضای کوکی سشن |
| `DATA_FILE` | خیر | مسیر فایل ذخیره‌سازی داده‌ها. پیش‌فرض `chop-data.json` در پوشه‌ی جاری |
| `PUBLIC_HOST` | خیر | اگه دامنه‌ی سفارشی داری و می‌خوای لینک‌ها دقیقاً همون دامنه رو نشون بدن |

## 📱 نصب به‌عنوان PWA روی موبایل

این پنل یک **PWA (Progressive Web App)** کامل است و می‌توانی آن را روی موبایل نصب کنی تا مثل یک اپلیکیشن بومی کار کند.

### روی Android (Chrome)
1. با Chrome به آدرس پنل برو.
2. وارد شو (با `2010` / `2010`).
3. روی منوی سه‌نقطه‌ی Chrome ( بالا سمت راست) بزن.
4. **«Add to Home screen»** یا **«Install app»** رو انتخاب کن.
5. تأیید کن. حالا آیکون Chop روی صفحه‌ی خانه‌ات ظاهر می‌شه و می‌تونی مثل یک اپ مستقل بازش کنی (بدون نوار مرورگر، تمام‌صفحه).

### روی iOS (Safari)
1. با Safari به آدرس پنل برو و وارد شو.
2. روی دکمه‌ی **Share** (پایین وسط، آیکون مربع با فلش بالا) بزن.
3. **«Add to Home Screen»** رو انتخاب کن.
4. روی **Add** بزن. آیکون Chop روی صفحه‌ی خانه ظاهر می‌شه.

### روی دسکتاپ (Chrome/Edge)
- وقتی وارد پنل بشی، یک دکمه‌ی **«نصب اپ»** گوشه‌ی بالا ظاهر می‌شه (اگه مرورگر از نصب PWA پشتیبانی کنه). روش بزن تا به‌عنوان اپ نصب بشه.

### مزایای نصب PWA
- **تمام‌صفحه**: بدون نوار آدرس مرورگر، مثل اپ بومی
- **آفلاین**: صفحه‌ی ورود و رابط کاربری کش می‌شن (داده‌ها هنوز نیاز به اینترنت دارن)
- **fast**: بارگذاری آنی از کش
- **Push notifications**: در نسخه‌های آینده

## 🎨 طراحی واکنش‌گرا (Responsive)

- **دسکتاپ**: سایدبار کناری + محتوای اصلی
- **تبلت**: همان دسکتاپ ولی فشرده‌تر
- **موبایل**: نوار ناوبری پایین + سایدبار کشویی (با دکمه‌ی «بیشتر»)
- **safe-area**: از notch موبایل‌های جدید پشتیبانی می‌کنه

## دیپلوی روی Railway

### از طریق GitHub (ساده‌ترین)
1. این پروژه رو به یه ریپوی گیت‌هاب پوش کن.
2. توی Railway: **New Project → Deploy from GitHub repo**.
3. Railway خودش Node.js رو تشخیص می‌ده، `npm install` و بعد `npm start` رو اجرا می‌کنه.
4. توی تنظیمات سرویس → **Networking**، یه دامنه‌ی عمومی بساز.
5. برو به `https://<دامنه‌ت>/` و با `2010` / `2010` وارد شو.

### پایداری داده‌ها با Volume (توصیه‌شده)
- توی Railway روی سرویس → **Settings → Volumes → Add Volume**.
- مسیر mount رو `/data` بذار.
- متغیر `DATA_FILE=/data/chop-data.json` رو اضافه کن.
- حالا بعد از هر ریستارت یا دیپلوی مجدد، داده‌ها سرجاشون می‌مونن.

### از طریق Railway CLI
```bash
npm install
railway login
railway init
railway up
```

## دیپلوی روی هر هاست Node.js (VPS، Render، Fly.io، …)

```bash
npm install
npm start
```

پورت پیش‌فرض ۳۰۰۰ است؛ با `PORT=8080 npm start` می‌تونی عوضش کنی.

## ربات تلگرام

بخش ربات تلگرام بدون هیچ تغییری کار می‌کنه — از پنل → تب «ربات تلگرام» → توکن
رو بذار و فعالش کن.

## بکاپ و بازیابی

از پنل → تب «بکاپ و بازیابی»:
- **دانلود بکاپ**: یک فایل JSON کامل.
- **دانلود CSV**: لیست کانفیگ‌ها برای اکسل.
- **بازیابی**: آپلود فایل JSON بکاپ (جایگزینی کامل یا ادغام).

## امنیت

⚠️ یوزر/پسورد پیش‌فرض `2010/2010` است. **حتماً قبل از استفاده‌ی واقعی** در
Environment Variables مقدارهای قوی‌تری برای `ADMIN_USER` و `ADMIN_PASS` ست کن.
